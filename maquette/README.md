# Maquette validée — référence visuelle

Ces 4 fichiers HTML sont la maquette validée du site (faite avant le développement).
Ouvre-les dans le navigateur pour les voir.

- `01-accueil-desktop.html` — accueil desktop (13 sections)
- `02-accueil-mobile.html` — accueil mobile (390 px), avec la barre fixe Appeler / WhatsApp
- `03-service-mobile.html` — template de page service (exemple : cataracte)
- `04-accueil-arabe-mobile.html` — accueil en arabe (RTL)

Règles pour Claude Code :
- C'est une **référence visuelle** (couleurs, typo, espacements, ordre des sections, textes).
  Ne copie pas ce code tel quel : il est écrit en styles inline pour la maquette.
  Reconstruis-le proprement (CSS avec variables, partials, propriétés logiques, mobile-first)
  selon CLAUDE.md.
- Les textes entre crochets `[…]` sont des placeholders : garde-les visibles.
- Les animations prévues ne sont pas dans la maquette : voir « Plan d'animations » dans CLAUDE.md.
- Les images de `images/` sont des versions compressées ; les originaux sont dans `assets-source/`.
